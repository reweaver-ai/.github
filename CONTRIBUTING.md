# Contributing to ReWeaver AI

Thanks for your interest in contributing. These are the default contribution guidelines for all repositories under the [ReWeaver AI](https://github.com/reweaver-ai) organization. Individual repositories may add their own `CONTRIBUTING.md` that takes precedence over this one.

## What's open

We're in early alpha. The core governance engine isn't public yet — but the prompt-layer starting point is, and that's where outside contributions land today:

- **[survival-kit](https://github.com/reweaver-ai/survival-kit)** — the AI Coding Survival Kit: portable system prompts, rules files, and skills for AI coding assistants. New rules, drop-in configs for additional tools, and fixes are all welcome here.

If a repository is public and accepts issues and pull requests, it's open to contributions under these guidelines.

## Ways to contribute

- **Report a bug** or **request a feature** — open an issue using the templates.
- **Improve docs** — clarifications, fixes, and examples are genuinely valuable.
- **Submit a change** — see the pull request flow below.
- **Compare notes** — if you're wrestling with AI-generated code that *looks* done but isn't, we'd like to hear from you, contribution or not.

## Pull request flow

1. **Open an issue first** for anything beyond a small fix, so we can agree on the approach before you invest time.
2. **Fork and branch** from the repository's default branch with a descriptive branch name.
3. **Make focused changes** — one logical change per PR. Match the existing style and conventions of the repo you're working in.
4. **Test and lint** — make sure the repo's checks pass locally before pushing.
5. **Write a clear PR description** — what changed, why, and how to verify. Link the issue it closes.
6. **Be responsive to review** — we aim to respond promptly, and ask the same in return.

## Standards

- Keep changes scoped and reviewable; large unrelated reworks are hard to merge.
- Don't introduce silent fallbacks or error-masking — fail loud, surface problems. (It's the very thing the survival kit exists to prevent.)
- By contributing, you agree your contributions are licensed under the same license as the repository you're contributing to.

## Code of conduct

All participation is governed by our [Code of Conduct](./CODE_OF_CONDUCT.md). Be respectful and constructive.

## Questions

Not sure where something fits? Open an issue and ask, or reach us via [reweaver.ai](https://www.reweaver.ai). We're a small team and early — clear, kind, specific reports help enormously.
